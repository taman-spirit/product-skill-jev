# EP-001 - Telegram Bot Integration

**PRD:** PRD-001 | **Sprint:** S01 | **Priority:** P0 | **Version:** v1.0 | **Status:** approved

---

## 1. Epic Overview

### Goal

Enable Product Managers to interact with the AI PM co-pilot via Telegram, allowing them to capture feature requests, run RICE scoring, check project status, and receive contextual suggestions from any device.

### Scope

- Receive and process text messages from authorized users
- Stream AI responses back to the user
- Support file attachments (.docx, .pdf, .xlsx, .md)
- Show inline keyboard buttons for suggested next steps

### Out of Scope

- Group chat support
- Voice message transcription
- Bot analytics dashboard

---

## 2. User Stories

### US-001 - Send Feature Request

**As a** Product Manager,
**I want to** describe a feature in plain language to the bot,
**So that** a structured FR document is created automatically.

**Priority:** P0 | **Story Points:** 5 | **Status:** done

#### Acceptance Criteria

**Scenario 1 - Happy path: PM describes feature**
```
Given: PM is in a conversation with the bot
When:  PM sends "Create a feature request for dark mode in the settings screen"
Then:  Bot asks 2-3 clarifying questions (source, problem statement)
And:   Bot creates FR-NNN file in the active project
And:   Bot confirms "FR-001 created" with suggested next steps
```

**Scenario 2 - Edge case: No active project set**
```
Given: PM has not opened a project in this session
When:  PM sends "Create a feature request"
Then:  Bot asks "Which project is this for?" before proceeding
```

**Scenario 3 - Error: Empty message**
```
Given: PM sends an empty message or only emoji
When:  Bot receives the message
Then:  Bot shows the help menu with common commands
```

#### Definition of Done

- [ ] FR file created in correct project discovery/inbox/ folder
- [ ] All AC scenarios verified by QA
- [ ] PM sign-off on demo

### US-002 - Score Feature with RICE

**As a** Product Manager,
**I want to** score a feature request through a guided conversation,
**So that** I get a RICE score with full formula shown.

**Priority:** P0 | **Story Points:** 5 | **Status:** done

#### Acceptance Criteria

**Scenario 1 - Complete RICE flow**
```
Given: FR-001 exists in the active project
When:  PM sends "Score FR-001 with RICE"
Then:  Bot asks Reach question with scale explanation
And:   Bot asks Impact question
And:   Bot asks Confidence question
And:   Bot asks Effort question
And:   Bot calculates RICE = (R x I x C%) / E and shows formula
And:   RICE-001 file is created in discovery/scoring/
```

**Scenario 2 - RICE below threshold**
```
Given: PM completes RICE scoring
When:  Calculated RICE score < 20
Then:  Bot shows score and suggests "This feature might fit better as a CR on an existing PRD"
```

**Scenario 3 - Interrupted flow**
```
Given: PM is mid-way through RICE scoring
When:  PM sends a different message (off-topic)
Then:  Bot acknowledges the interruption and offers to resume RICE or start fresh
```

### US-003 - File Attachment Support

**As a** Product Manager,
**I want to** send a document to the bot,
**So that** the AI can read it and use it as context for PM work.

**Priority:** P1 | **Story Points:** 5 | **Status:** done

#### Acceptance Criteria

**Scenario 1 - PDF attachment**
```
Given: PM has a research PDF or competitor analysis
When:  PM sends the file to the bot
Then:  Bot extracts text from the PDF
And:   Bot asks "What would you like to do with this file?"
And:   File is saved to _attachments/YYYY-MM-DD/
```

**Scenario 2 - Unsupported file type**
```
Given: PM sends a .mp4 video file
When:  Bot receives the file
Then:  Bot responds "I can't read .mp4 files. Supported: .docx, .pdf, .xlsx, .csv, .md"
```
